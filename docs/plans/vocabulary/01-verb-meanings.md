# 计划 1：动词含义

状态：核心需求已确认，待实施。当前仍处于整体规划阶段。

## 目标与现状

新增“展示法语动词，填写中文释义”的练习。当前内置动词数据包含原形、助动词和变位形式，没有含义字段；单词记忆中的自建词条已经支持释义，但使用翻卡与自评流程。

## 已确认需求（2026-10-22）

- 题目展示法语动词，用户输入中文释义。
- 释义语言为中文。
- 在“动词变位”页增加独立的“动词含义”模式。
- 填写后展示标准中文释义，由用户自行判断对错。
- 多义动词答出任意一个收录的常用义即可，答后展示其余含义。

## 实施安排

- 首期按现有 100 个内置动词编排，提供简明中文常用义。
- 作答期间显示法语原形与中文输入框，提交后保留用户输入并展示标准中文释义，以及“答对了 / 答错了”自评操作。
- 自评前不记录对错；选择后记录一次结果并允许进入下一题，重复点击不重复计数。
- 显示“答出任一常用义即可”的自评说明，不根据输入文本自动判分。
- 全站已确认的两个菜单入口保持为“单词记忆 / 动词变位”，进入后可在变位与含义两种模式之间选择。
- 释义题使用独立练习类型，避免与变位的时态、人称正确率混淆；后续与每轮数量、错题和复习计划衔接。

## 实施步骤

1. 已完成核心需求确认：独立含义模式、法语到中文、展示标准答案后自评、任一常用义通过。
2. 建立以动词原形为键的标准中文释义数据，覆盖现有 100 个动词。
3. 使用可靠词典来源核对多义词、常见表达及易混淆词，保留来源记录。
4. 实现中文输入、提交、结果反馈与下一题流程；支持中文输入法组合输入，避免选字时误提交。
5. 实现“答对了 / 答错了”自评与结果记录，区分释义与变位的练习结果；与第 2 项轮次和第 3 项错题数据设计衔接。
6. 验证答案隐藏与展示、自评前后状态、重复操作、模式切换及中文输入法行为，执行相关测试和构建。

## 验收标准

- 所有纳入范围的动词均有正确、可读的释义。
- 法语动词为题目，中文释义为作答内容；提交前不直接展示标准答案。
- 提交后展示标准答案，由用户选择对错；自评结果准确进入本轮统计，未自评不算已完成。
- 多义词展示全部收录常用义，并明确任一常用义即可；答案文字本身不会触发自动判分。
- 中文输入法选字不会误提交，结果反馈和本轮统计一致。
- 不改变已有变位形式及判题规则。

## 确认记录（2026-10-22）

- 用户选择在“动词变位”页增加独立“动词含义”模式。
- 用户选择“填写后展示标准答案，由我自行判断对错”。
- 用户选择“答出任意一个收录的常用义即可，答后展示其余含义”。
