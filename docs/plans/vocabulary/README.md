## 已确认需求

- 第 4 项：桌面下拉菜单、手机点击展开，两个入口名为“单词记忆 / 动词变位”。
- 第 1 项：动词变位页内独立“动词含义”模式，展示法语动词、填写中文释义；查看标准答案后自评，答出任一常用义即可。
- 第 2 项：三种练习均支持 10、20、30、50 加自定义；变位按组合题数计数，含义与单词记忆按不同词条计数。
- 第 3 项：三种练习均记录错题，单词记忆仅“忘记”算错；采用 10 分钟、1、3、7、14、30 天的复习间隔。答对推进，答错回首阶段，最后阶段通过后标记掌握。到期错题优先且计入本轮数量，并提供“只练错题”。

## 实施交付顺序

当前关卡：第 4 项已实现并验证，等待用户确认；第 1、2、3 项尚未开始实现。

1. 第 4 项：调整全站导航和两页同级切换，验证桌面、手机和键盘操作。
2. 第 1 项：补齐 100 个动词释义，加入中文输入与自评流程，区分含义和变位结果。
3. 第 2 项：统一三种练习的轮次数量、进度和完成状态。
4. 第 3 项：加入错题持久化、间隔调度和复习队列，完成跨功能验证。

每项均按独立计划的验收标准完成检查；涉及数据的功能还需验证账号隔离、重试去重和旧进度兼容。实现时的数据库具体变更以届时复核结果为准。

## 已列明的实施默认

- 数量默认 10，分模式记住上次选择；刷新后保留已提交结果，重新开始本轮。
- 保留单词记忆每日 30 个新词额度；候选不足时显示实际数量和原因。
- 本轮不追加重复错题；提前答对不跳过复习间隔；旧进度继续保留。
- 首期提供站内到期提醒，记录题目与复习状态，不额外保存完整逐题输入或增加站外通知。

这些是为衔接已确认需求而制定的实施安排，不另行标为用户明确选择。
