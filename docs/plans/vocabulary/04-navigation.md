# 计划 4：“背单词”菜单下并列两个入口

状态：已实现并验证，等待用户验收确认；第 1 项尚未启动。

## 目标

用户从全站“背单词”菜单直接选择“单词记忆”或“动词变位”，两者处于同一层级。

## 现状

- `src/components/Header.astro` 共用导航数据生成桌面和手机导航。“背单词”直接进入 `/vocabulary/`。
- `src/pages/vocabulary.astro` 是标准背词页，页内有通往 `/vocabulary/conjugation/` 的次级链接。
- `src/pages/vocabulary/conjugation.astro` 通过“返回背单词”回到标准背词页。

## 已确认方案

- 桌面：点击“背单词”展开菜单，同级显示“单词记忆”和“动词变位”；不依赖悬停。
- 手机：点击“背单词”展开相同两个选项，控制位置与宽度，避免被横向导航容器裁切。

## 实施安排

- 保留两个已有页面地址与登录回调地址，降低入口调整的影响。
- 两个页面顶部增加一致的同级切换入口，移除“进入变位／返回背单词”的上下级表达。
- 学习页面高亮所属的“背单词”菜单，并在子项准确标记当前页面。

## 实施步骤

1. 已完成需求确认：桌面和手机均点击展开，选项名为“单词记忆 / 动词变位”。

4. 为两个学习页面增加同级切换，更新相关说明。
5. 验证全站导航、两个学习页与移动布局。

- 桌面和手机均可使用，无悬停操作前提、遮挡或菜单裁切。
- 当前子项标记准确，切换语言后文案与无障碍名称同步。
- 键盘能够操作菜单并正常退出；主题及原有语言菜单正常。
- 两个页面已有登录会话与学习功能正常；执行构建与桌面／手机交互检查。
