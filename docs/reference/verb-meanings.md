## 参考来源

- [devoir](https://www.frdic.com/dicts/fr/devoir)：义务、欠款及推测用法。
- [rendre](https://www.frdic.com/dicts/fr/rendre)：归还、使变得及提供服务。
- [tenir](https://www.frdic.com/dicts/fr/tenir)：拿着、保持及支撑。
- [sentir](https://www.frdic.com/dicts/fr/sentir)：感觉与气味相关用法。
- [entendre](https://www.frdic.com/dicts/fr/entendre)：听见与理解。
- [visiter](https://www.frdic.com/dicts/fr/visiter)：参观与探望的适用情境。
- [apprendre](https://www.frdic.com/dicts/fr/apprendre)：学习、获悉及教会。

核对日期：2026-10-22。这里只记录参考关系，释义采用简短词义编排，不转载词典例句或完整词条。

## 编排注意

- `savoir` 包含知道事实和会做某事，`connaître` 用于认识或了解；不混入独立代词式动词的专有义。
- `visiter` 首列参观、游览；表示探望时限定病人等情境，日常拜访某人常用 `rendre visite à`。
- `sortir`、`monter` 等含多种及物／不及物常用义，释义模式不限制助动词；现有变位题的助动词约定继续保留。
- 英文界面切换只改变操作文案，作答内容和标准答案始终为中文。
