# DELF B1–B2 词库审校与导入

完成日期：2026-10-26。

原文件为 `DELF B1-B2_20261026_1610.csv`，共 2,970 个不同词条。按确认的要求保留 B1–B2 学习中较常用的义项，精简生僻、历史和过细的技术义项。原表中的罕用词仍保留，在适用词条中注明罕用、旧称或专业领域。

## 交付文件

- `DELF_B1-B2_reviewed.csv`：与网站数据库匹配的 `word / meaning / example` 三列，UTF-8 BOM 编码，逗号、引号和换行均按 CSV 格式转义。
- `review-audit.json`：逐词记录原始词形、音标、原释义、整理后释义、例句、语料来源与署名。原表音标保存在此审校记录中，未新增网站数据库字段。
- `previous-vocabulary-backup.json`：替换前的 37 个词条及其学习字段、单词错题和作答记录备份。替换前没有已学习词条、单词错题或单词作答记录。
- `validation.json`、`import-manifest.json`：导出校验、内容指纹与替换数量记录。

## 审校结果

全部 2,970 个词条均已按常用词义核对，并逐条检查例句中的目标词、词义与语法。保留或整理了 2,462 条公开语料例句，另补写或重写 508 条，已替换同形词误匹配和明显不自然的候选句。

部分纠正如下：

| 词条 | 原释义中的问题 | 整理后常用义 |
| --- | --- | --- |
| abonnement | 仅解释为“预约、预订” | 订阅；订阅套餐 |
| alarmant | 仅写“惊人” | 令人担忧的 |
| besoins | “经济”不符合常用含义 | 需要；需求 |
| bouché | 与 bouchée 的“一口食物”混淆 | 堵塞的；不通的 |
| caritatif | 将形容词解释成“慈善机构” | 慈善的 |
| consultable | “搜索”词性与含义均不准确 | 可查阅的 |
| diabète | 将常用义写成“尿崩症” | 糖尿病 |
| mutualiser | 释义局限于医疗互助会 | 共享；整合共用资源 |
| trimestriellement | 将副词解释为“季刊” | 每季度；每三个月一次 |
| végétalisation | “植物化”不符合常用城市语境 | 绿化；植被覆盖 |

规范了三处词形：`chef-d'oeuvre → chef-d'œuvre`、`hors-d'oeuvre → hors-d'œuvre`、`Observateur → observateur`。其余词条保持原词形。代词式和必要介词在释义中补明，如 `s'agenouiller`、`s'emparer de`、`dépendre de`。

## 来源与例句署名

公开语料来自 [Tatoeba 法语句库](https://downloads.tatoeba.org/exports/per_language/fra/)。采用的例句在 `example` 字段中附作者、句子链接和 CC BY 2.0 FR 许可说明；未署名句子保留其原页面链接。署名规则见 [Tatoeba 语料使用说明](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus)。

少量罕用术语额外参考了 [Larousse 的 analogisme 词条](https://www.larousse.fr/dictionnaires/francais/analogisme/3225)、[法兰西学院关于 aberrer 的说明](https://www.dictionnaire-academie.fr/article/QR_0583)和 [北京大学收录的内吗啡肽研究记录](https://ccj.pku.edu.cn/article/info?aid=275800232)。
